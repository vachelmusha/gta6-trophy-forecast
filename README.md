Forecasts every Grand Theft Auto VI PS5 trophy's Exophase earn rate a week after launch as five quantiles, using a damped logit-vs-log-time trend fitted only on the pages Exophase actually refreshed, after separating out the handful of early-access players who hold every trophy. Standard-library Python, with a synthetic backtest in `backtest/`.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
